# OkaiageZeigakuGaeshi
OkaiageZeigakuGaeshi  ※APIプログラムソースコード※オープンソースVer.1
◆お買い上げ税額返し（※領収証orレシート発行都度実行プログラム）

OkaiageZeigakuGaeshi(
引数：
取引日時,
レシートNo,
顧客ID,
商品コード（※JAN/EAN/他など）,
単価（※前提：税抜,小数点以下2桁（1銭の桁）までの数値型）,
数量,

戻り値：
0：ReceiptGyoubangou（※あれば,1以上整数,※ゼロ：1商品のみレシートor総額のみレシート）,
1：ShouhinCode（※あれば,半角英数字記号,1000バイト）,
2：Zeiritsu（※必須,小数点以下2桁整数,＋0.00〜1.00,※商品毎税率テーブル参照取得）❗【代替応用：軽減税率対象か否かフラグでも良い⇒対象：0、対象外：1で除外、または過去消費税制度上テーブル設定が2％（0.02）未満なら税額ゼロ、100％（1.00）なら除外など】,
3：TanpinZeigaku（±0以上整数※数量：±1の時、あれば算出結果⇒単価✕数量✕税率の「まるめ額」★）,
4：FukusuuZeigaku（±0以上整数※数量：±2以上の時、あれば算出結果⇒単価✕数量✕税率の「まるめ額」★）,
5：GoukeiZeigaku（±0以上整数※必須※算出結果⇒3＋4の「まるめ額」★）
)
★「まるめ額」とは、算出税額の小数点以下一桁目（つまり十銭以上九十九銭以下）を端数処理（切上/四捨五入/切捨）した￥日本円額
