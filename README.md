★💡理解ポイント
国やその地方出先機関に飲食料品の消費税を納めるタイミングと方法を理解しましょう🔦
上記の「消費税等」軽減税率制度や1%暫定税率などの消費税は
【消費者がその商品を買うときに商品代金と合わせて支払う】ということ。
つまり相手（お店：売主）は商品代金と合わせて（お客：買主から）消費税を預かる。お店は仮り受けした消費税を国などに納付する。
※メルカリなどで商品を売り買いしたことがある方もいると思いますが、個人間の商品売り買いには（商品代金だけで）消費税はかかりません。消費税が発生するのは商業者（お店や事業主）から消費者（お客さん）が商品を買うときに消費税がかかります。
つまり8%から1%に暫定的に減税する、その「財源が明示されていない」というトンチンカンな反対意見の財源とは、消費者から税をとる国（またはその出先機関）が消費者に対して「食料品が高くて買えない人に食料品から消費税何％分でも税率を下げる暫定措置すらしない」ということで、毎日あなたたちは何を食べているの❓️って市民として逆に問いたいですわ。消費税率暫定減税に財源明示の問題などで反対している国会議員は練りわさびチューブを8個（または練りわさびチューブ＋おろし生姜チューブ＋ねりからしチューブ＋ねり梅チューブ＋ねりごまチューブ＋おろしニンニクチューブ＋コチュジャンチューブ＋ねりラー油チューブ）買って消費税8円払えばいいだけのお話しです（ご自身で7%分多く消費されてその分消費税を多く支払えばいいだけのお話です）。
❗“消費税”は「（日本国が）消費する人にかけられている税金」で「（食べものを）買う時点で支払うもの」です❗
ちなみに完熟アボカド刺身をわさび醤油にちょっとつけて食べたらこの猛暑中でも食欲マシマシで美味しく食べられます（主食ごはんでも、そうめんでも、おそばでも、主食なしでも）✌
